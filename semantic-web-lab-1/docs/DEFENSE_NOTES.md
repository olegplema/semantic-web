# Короткі тези для захисту

1. **Предметна область:** навчальні програмні проєкти та мови програмування. Дані створені як демонстраційний набір (не взяті з реального каталогу).
2. **RDF-трійка:** суб’єкт, предикат, об’єкт. Наприклад, `ex:backendApi ex:usesLanguage ex:Java`.
3. **Графи:** `ex:local` містить авторські ресурси; `ex:external` — невеликий локальний знімок тверджень Wikidata. `Dataset` забезпечує обидва графи.
4. **Зв’язки:** `ex:Java skos:exactMatch wd:Q251` і `ex:Python skos:exactMatch wd:Q28865`. Предикат позначає точну відповідність концептів із двох словників.
5. **SPARQL:** команда `PYTHONPATH=src python -m semantic_lab query --name 02_federated_local_join.rq` демонструє JOIN по `?wikidataEntity` і два `GRAPH`-блоки.
6. **Результат:** чотири рядки: три проєкти, з них один використовує дві мови.
7. **Помилка:** `ex:backendApi owl:sameAs wd:Q251` неправильно стверджує, що проєкт — це сама мова Java. Коректний предикат між проєктом та мовою — `ex:usesLanguage`.
8. **Візуалізація:** відкрити `output/graph.html`. Якщо Graphviz встановлено, там є SVG-діаграма.
9. **Перевірка:** `PYTHONPATH=src python -m unittest discover -s tests -v`, 5 тестів.
10. **Чесне обмеження:** зовнішні факти — знімок, а не оновлювана онлайн-копія Wikidata. Результат SPARQL включає дані з обох іменованих графів, але не виконує мережевого federated SERVICE.

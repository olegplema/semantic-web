# Підказки для демонстрації коду

Предметна область: надійність і спостережуваність подієвих мікросервісів. У корпусі шість авторських документів. Запитання містяться в `data/questions.json`.

Сутності — техніки та проблеми (Idempotent consumer, Consumer lag тощо). Зв'язок — короткий предикат із зазначенням `doc`. Граф — `networkx.DiGraph`; Louvain працює на неорієнтованій проєкції графа.


Для локального пошуку є два базові методи: keyword = кількість спільних токенів, vector = TF-IDF + cosine. Семантичні ембеддинги — опціональний `--search semantic`. Це важливо: TF-IDF є векторним методом, проте не dense semantic embedding.

GraphRAG: факти -> граф -> спільноти Louvain -> один LLM-виклик на спільноту -> LLM-синтез резюме. Vector-RAG: top-K чанків -> один LLM-виклик без графа. Порівняння автоматично показує джерела обох шляхів; змістовні висновки про повноту слід перевірити вручну.

Під час захисту покажіть `output/knowledge_graph.png`, `output/communities.json`, `output/retrieval_comparison.json`, `output/comparison.md`. Ручну перевірку фактичних тверджень проведіть за текстами з `data/documents`.

Можливий реальний збій на практиці: Ollama не запущена або модель не завантажена. Перевірка `ollama list`, виправлення `ollama pull gemma3:4b` та запуск сервера. Не називайте цю ситуацію власною реальною помилкою, якщо з нею не стикалися.
